# 西藏经典行程路线地图导览

Tibet Classic Routes Interactive Map

基于马蜂窝北极星攻略《西藏经典行程推荐》，展示西藏10条经典路线的交互式地图导览。

## 包含路线

### 西藏境内经典线（4条）
- 拉萨+羊湖+珠峰+纳木错 8日游
- 林芝+山南+羊湖 8日环线
- 阿里南线 9日
- 阿里大北线 15日

### 进藏自驾线路（6条）
- 川藏南线 G318
- 川藏北线 G317
- 青藏线 G109
- 滇藏线 G214
- 丙察察线
- 新藏线 G219
- G345 青藏新线

## 技术栈
- 纯HTML/CSS/JS单文件
- Leaflet.js + OpenStreetMap
- Apple风格UI设计
